Solvane Hotel

A premium hotel website concept built around quiet luxury, editorial design, and a seamless guest experience.

Solvane is a responsive multi-page hotel website designed to present a complete digital experience for a fictional hospitality brand — from discovering rooms and amenities to exploring the gallery and submitting a reservation request.

«Designed & built by Muhammad Jubril (MJ)»

✨ Features

- Luxury hotel homepage with editorial hero presentation and immersive imagery.
- Rooms & Suites with detailed room information and interactive room experiences.
- Amenities section with visual browsing and image lightbox interactions.
- Gallery for exploring the hotel's visual identity and spaces.
- Booking flow that carries selected dates, guests, and room information between pages.
- Reservation request form with a WhatsApp handoff for submitting booking details.
- Responsive navigation designed for desktop and mobile experiences.
- Page transitions and subtle motion throughout the experience.
- Scroll-triggered reveals for progressive content presentation.
- Room comparison / detail interactions for exploring accommodation options.
- Responsive image handling with lazy loading and optimized loading priorities.
- Reduced-motion support for users who prefer less animation.
- Floating WhatsApp contact action for direct guest communication.

🎨 Design Direction

Solvane was designed around the idea of quiet luxury rather than traditional hotel-site aesthetics.

The visual system combines:

- Editorial typography
- Large-scale photography
- Dark earthy tones
- Soft contrast
- Subtle grain
- Generous spacing
- Restrained motion
- Asymmetric layouts

Typography uses Bodoni Moda for the editorial display language and Manrope for interface and supporting content.

The result is intended to feel closer to a premium hospitality brand than a conventional template-based hotel website.

📅 Reservation Flow

The booking experience is intentionally lightweight.

A guest can select:

- Check-in date
- Check-out date
- Number of guests
- Room type

The selected information is passed into the dedicated booking page, where the guest can complete additional details before submitting the reservation request.

The final submission uses a WhatsApp handoff rather than a server-side reservation database.

Important scope note

Solvane is a frontend hotel website concept.

It does not currently include:

- A hotel database
- Real-time room availability
- Online payment processing
- Server-side reservation management
- Guest accounts
- Automated booking confirmation
- Hotel administration dashboard

The booking interface demonstrates the guest-facing reservation experience, rather than a complete hotel management system.

- Mobile phones

🚀 Running Locally

Solvane is a static frontend project and does not require a backend server for the core experience.

Clone the repository:

git clone https://github.com/muhammad-jubril/Solvane-hotel.git
cd Solvane-hotel

Then open "index.html" in a browser or serve the project using a local development server.

🎯 Project Goals

Solvane was created to explore how a hospitality website can combine:
